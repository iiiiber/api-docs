## 项目背景

2026 年 3 月开始做旧衣回收，目标：通过闲鱼 + 微信群接单，用户寄衣服 → 我对接 API 卖给飞蚂蚁/白鸽等回收平台。

## 数据

- 总订单：~10 单
- 总收入：~150 元
- 推广成本：~300 元（闲鱼付费推广）
- 净利润：-150 元（亏）
- 时间投入：每天 30-60 分钟回消息

## 失败原因

### 1. 流量端不匹配

旧衣回收本质是线下扫码 + 上门取件的生意，流量来源应该是小区/学校/工厂。我只在线上做（闲鱼/微信），用户没线下习惯，转化极低。

### 2. 付费推广 ROI 极差

闲鱼付费推广 ~100 元/次，每次 0-2 单，平均 ROI < 50%。连续 3 个月推广 = 持续亏损。

### 3. 平台截流严重

飞蚂蚁、闲鱼小程序、白鸽回收都在做，用户搜「旧衣回收」直接被大平台截流。我接 API 没有流量/税务优势，提现被吃光。

### 4. 时间成本失控

虽然订单少，但每天要回消息、协调快递、处理售后。没收益的精力消耗比亏钱更难受。

## 核心教训

- **流量来源决定 ROI**：线下扫码类项目不适合纯线上玩家
- **付费推广前先算账**：连续 3 个月亏损就止损
- **沉没成本不是成本**：3 个月投入要放下，专注有效项目
- **技术杠杆要能变优势**：API 对接没壁垒，等于没壁垒

## 后续方向

副业项目选型原则：

- ✅ 线上推广能闭环
- ✅ 轻资产、低启动成本
- ✅ 现金流好、不靠烧钱
- ✅ 技术能力能变成杠杆（不是单纯接 API）
