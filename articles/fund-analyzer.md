## 项目定位

| 项目 | 定位 |
| --- | --- |
| fenxi.imoons.cn | 股票每日分析 + 组合管理 + 回测 |
| fund-analyzer | 基金每日筛选 + 持仓管理 + 组合回测 |

## 核心目标

- 替代现有散乱的基金分析流程（支付宝、京东金融、雪球、且慢等）
- 提供统一的基金筛选、持仓管理、组合分析能力
- 接入且慢 MCP 数据源，获取权威基金数据

## 数据源

| 数据源 | 用途 | 状态 |
| --- | --- | --- |
| 且慢 MCP (qieman-mcp) | 基金净值、持仓、诊断、回测 | 已有技能 |
| 天天基金网（非官方） | 历史净值补充 | 待开发爬虫 |
| 支付宝（用户手动） | 持仓导入 | 现有 CSV 导入 |
| akshare | 基金基础数据、筛选 | 已有技能 |

## 技术栈

```
前端: Vue 3 + TypeScript + Vite + TailwindCSS + Recharts
后端: Node.js + Express（复用 api.imoons.cn 现有架构）
数据层: PostgreSQL（复用现有数据库）
数据源: 且慢 MCP + akshare + 天天基金网爬虫
部署: Cloudflare Pages（前端）+ 宝塔服务器（后端）
```

## 核心模块

### 1. 基金筛选

- 多维度筛选：基金类型、规模、收益率、夏普比率、最大回撤
- 自定义筛选任务，支持定时执行
- 筛选结果可视化对比

### 2. 持仓管理

- CSV/Excel 批量导入持仓
- 实时估值（结合今日净值估算）
- 盈亏分析 + 风险评估

### 3. 组合回测

- 基于历史净值组合回测
- 支持定期再平衡策略
- 输出年化、夏普、最大回撤等指标

### 4. AI 诊断

- 调用 LLM 生成基金诊断报告
- 基于持仓 + 市场行情的智能分析
- 支持多轮对话

## 下一步

从 MVP 开始，先做基金筛选 + 持仓管理两个核心模块，跑通后接入回测和 AI 诊断。
