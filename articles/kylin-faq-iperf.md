## 使用场景

网络带宽测试工具，支持 TCP 和 UDP 协议测试，可测量网络最大吞吐量、延迟、抖动等指标。

## 操作步骤

### 步骤 1：安装

```
sudo apt-get install iperf
```

### 步骤 2：启动服务端

```
iperf -s
```

### 步骤 3：TCP 带宽测试

```
iperf -c 192.168.1.100
```

### 步骤 4：UDP 带宽测试

```
iperf -c 192.168.1.100 -u -b 100M
```

### 步骤 5：双向带宽测试

```
iperf -c 192.168.1.100 -d
```

## 提示

- UDP 测试可测出实际能跑到的最大带宽
- TCP 测试结果更接近实际应用场景
- -P 参数指定并行流数
- 银河麒麟服务器注意防火墙规则

## 带宽低于预期排查

**问题**：iperf 测试带宽远低于实际网络带宽
**原因**：

- TCP 窗口大小不足
- 中间设备限速或存在瓶颈
- 客户端 CPU 单核性能不足
**解决**：

- 用 UDP 模式测试：iperf -c 192.168.1.100 -u -b 1000M
- 调整 TCP 窗口：iperf -c 192.168.1.100 -w 4M
- 多线程并行：iperf -c 192.168.1.100 -P 4
